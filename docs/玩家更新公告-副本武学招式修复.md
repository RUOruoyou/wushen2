# 玩家更新公告草稿

## 标题

【江湖修复】副本武学与装备修正

## 摘要

修复桃花岛及后续副本产出的部分武学残页在学习后没有绝招，以及副本专属装备说明和属性与掉落资料不一致的问题。

## 主要更新

- 重新核对桃花岛至战神殿副本产出的新增武学，修正武学对应的内功、轻功、拳脚、剑法、暗器、招架等类别。
- 恢复弹指神通、落英神剑、蛤蟆功、斗转星移、六脉神剑、黯然销魂掌、九阴神功、太玄功、慈航剑典、战神图录等武学的绝招。
- 共补齐 58 个绝招，包括伤害、连击、点穴、封招、恢复、护体、状态清除、反击和群体效果等不同战斗机制。
- 修正相关武学装备后的属性显示，使其与副本掉落说明保持一致。
- 重新核对 48 件副本专属装备，修正装备说明、基础属性、百分比词条、孔位和穿戴条件。
- 恢复部分装备的武学等级加成、绝招冷却/释放、内力消耗、减伤、忽视忙乱、反伤、吸血和概率破防等效果。
- 补齐战神殿四件装备的套装效果，集齐四件后可获得攻击、命中、招架、躲闪和防御提升。
- 已经学会相关武学的角色无需重新学习，原有武学等级和进阶记录继续保留。

## 玩家提示

- 维护结束后请重新打开技能面板查看新增绝招；需要自动释放的招式，可在绝招配置中重新确认启用状态和顺序。
- 已持有的副本装备无需重新获取，维护后会按修正后的装备定义生效；请重新查看物品详情确认属性。
- 本次仅修复副本武学和装备定义，没有调整副本敌人数值、掉落概率或扫荡收益。
- 如发现某个绝招无法使用，请提供武学名称、招式名称、当前装备和战斗提示，便于进一步定位。
