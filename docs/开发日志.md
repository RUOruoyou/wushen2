### 神照经武学重写：双装备位 + 神照/拳经绝招（已开发，待验证发布）

按 1000 级满级参考数值重写神照经，使其可同时装备为「基本内功」和「基本拳脚」，并为新增的「拳经」绝招实现固定数值吸收护盾。

主要改动：

- `world/skill/force/shenzhaojing.js`：完全重写。
  - `can_enables` 由 `["force"]` 扩展为 `["force", "unarmed"]`，新增拳脚普通攻击描述 `attack_actions`。
  - 内功装备属性（1000 级满级）：臂力/根骨/身法/悟性各 +176、内力上限 +150000、内力 80% 转化为气血（`force_rad = 0.80` 保留）。
  - 拳脚装备属性（新增，1000 级满级）：攻击 +1700、命中 +1700、臂力 +210、根骨 +210。
  - 绝招由「照心」「续脉」替换为「神照」「拳经」：神照（60 秒冷却）30 秒内提升根骨/臂力/身法；拳经（20 秒冷却）为纯臂力加成直拳，命中后施加固定数值吸收护盾，护盾存在期间拳经冷却额外减少 30%。
- `world/extends/char/combat.js`：新增通用护盾机制。
  - 在 `damage()` 的 `query_dao_damage_taken` 之后、最终扣血之前插入 `query_shield` 钩子，使任意装备方式施加的护盾都生效（原有 `force_skill.on_damage` 钩子只在装为内功时触发，无法覆盖装为拳脚使用拳经的场景）。
  - 新增 `CHARACTER.prototype.query_shield`，用 `set_temp("shield", 值, 时长)` 维护护盾池，受伤时优先扣除护盾值，扣完才扣真实气血，并保留护盾剩余时长。

数值公式（由 1000 级满级反推）：

| 维度 | 公式 |
| --- | --- |
| 内功 全属性（str/con/dex/int） | `parseInt(lv * 0.17) + 6` |
| 内功 内力上限 | `lv * 150` |
| 内功 气血上限 | `lv * 16` |
| 拳脚 攻击/命中 | `parseInt(lv * 1.7)` |
| 拳脚 臂力/根骨 | `parseInt(lv * 0.21)` |
| 神照 buff 根骨/臂力/身法 | `parseInt(lv * 0.21)`，持续 30 秒 |
| 拳经伤害（纯臂力） | `me.str * (8 + parseInt(lv / 50)) + lv * 6` |
| 拳经护盾（纯臂力） | `me.str * (12 + parseInt(lv / 40)) + lv * 30`，持续 10~18 秒 |

### 采集工具加成未生效修复（已改完，待游戏内验证）
