| 品级 | 武学 | 类型 | 可激发 | 简介 |

| Grade 1 | 血刀戒法 | 刀法 | blade, parry | 入门戒刀，练劈削缠锁 |

---

#### 🔥 核心被动：愈伤愈狂

```
攻击伤害加成 = gj × (已损失气血百分比) × 2%
```

气血每降低 1%，攻击力额外提高 2%。满血时无加成，残血时伤害飙升！

---

#### 🔥 核心被动：刀创（流血）

当命中且未被闪避/招架时，有几率附加「**刀创**」debuff：

- 持续 12 秒（4 跳，每 3 秒一跳）
- 每跳伤害：`lv/6 + gj/20 + 20`
- 内置 CD：9 秒

**攻击招式：**
- 「血影横江」刀光贴雪气
- 「回风饮血」刀锋折转
- 「雪岭开锋」暗红刀弧
- 「残阳照血」直取要害
- 「血海翻涛」层层刀影
- 「寒刃入骨」贴地反撩

## 战斗策略

### 核心机制联动

```
┌──────────────────────────────────────────────────┐
│                  血刀门战斗循环                      │
│                                                    │
│  掉血 → 愈伤愈狂(增伤) → 低血量触发拳掌增强          │
│    ↓                        ↓                      │
│  血祭(不死)           金刚佛嗔(高伤+破防)           │
│    ↓                        ↓                      │
│  血魔(全属性提升)     修罗降世(5连击)               │
│    ↓                                               │
│  血海魔刀(吸血) ← 嗜血(攻速+攻击)                   │
│    ↓                                               │
│  噬血穹苍(进入噬血) → 赤炼神刀(消耗流血爆发)         │
│     ↓                                               │
│  普攻吸血 → 血量恢复 → 循环                          │
└──────────────────────────────────────────────────┘
```

### PVE 连招推荐

1. **起手：** 天马行空 → 控制敌人 + 自身闪避命中提升
2. **挂流血：** 血刀刀法普攻 → 触发刀创流血
3. **控制链：** 大手印 → 延长敌人无法行动时间
4. **爆发：** 嗜血 → 血海魔刀（六连斩+吸血）
5. **残血反杀：** 金刚佛嗔（气血低于一半时伤害飙升）+ 修罗降世（五连击）

### PVP 连招推荐

1. **试探：** 金刚印 → 测试敌方防御
2. **爆发前置：** 血魔 → 全属性提升 20%
3. **控制：** 天马行空 → 贴身后使敌人忙乱
4. **输出核心：** 噬血穹苍 → 进入噬血状态 → 赤炼神刀
5. **保命：** 血祭 → 关键时刻 9 秒不死免控
6. **收割：** 血海魔刀 → 六连斩收尾 + 回血

### 注意事项

- ⚠️ 血刀门武学大多以**损失气血为代价**换取爆发，注意血量管理
- ⚠️ 血祭结束后有 **9 秒虚弱期**（全属性 -30%），需提前规划
- ⚠️ 嗜血状态每次攻击消耗 1% 当前气血，攻击速度越快掉血越快
- ✅ 血海魔功的 70% 内力转气血配合吸血效果，续航极强
- ✅ 残血时伤害最高，不要一味回血，控制好血量输出最大化
- ✅ 赤炼神刀消耗目标的流血效果换取 30% 额外伤害和更高破防，注意技能释放顺序
