## 验证命令

```bash
node scripts/validate-fb-routes.js
node scripts/validate-fb-drops.js
node scripts/validate-fb-difficulty.js
node scripts/validate-fb-migration.js
node scripts/validate-fb-effective.js
node scripts/validate-fb-equipment.js
node scripts/validate-fb-skills.js
node scripts/validate-fb-loot.js
node scripts/validate-fb-sweep.js
node scripts/validate-fb-sweep-stats.js
node scripts/validate-fb-lifecycle.js
node scripts/validate-fb-thresholds.js
node scripts/validate-fb-online.js
WSMUD_VALIDATE_RESOURCES=1 node main.js 100
WSMUD_VALIDATE_RESOURCES=1 WSMUD_VALIDATE_DROPS=1 node main.js 100
```

`WSMUD_VALIDATE_RESOURCES=1` 只执行世界资源加载，不读取或保存全局运行数据、不启动 WebSocket 监听；校验完成后会关闭数据库并以状态 0 退出。即使加载过程中收到 `SIGINT`，资源校验关闭分支也只会关闭数据库连接，不会执行正常服务器的数据保存流程。
增加 `WSMUD_VALIDATE_DROPS=1` 后会尝试创建所有技能残页及 AREA 展示/扫荡掉落对象，用于发现运行时资源路径错误；它仍不会启动网络监听或写入玩家数据。
