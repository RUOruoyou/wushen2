# 玩家更新公告

> 状态：已于2026-08-12发布，公告ID：`notice_56a549699846e79251c03856`。

## 标题

【江湖优化】自动任务恢复功能

## 摘要

自动师门和自动追捕新增任务间恢复设置，可按设定比例自动恢复气血与内力后再继续下一名目标。

## 主要更新

- 设置界面的“扩展”页新增“任务间自动恢复”开关。
- 可分别设置气血和内力恢复比例，范围为1%至100%。
- 自动师门或自动追捕完成一名目标后，气血不足时会先疗伤，内力不足时会再打坐。
- 气血和内力均达到设定比例后，系统才会继续下一名任务目标。
- 原有自动师门、自动追捕流程保持不变；关闭开关后不会触发任务间恢复。

## 玩家提示

- 功能默认关闭，默认恢复比例为气血80%、内力60%，可在设置中自行调整。
- 主动停止恢复或放弃任务后，系统不会自动开始下一名目标，可通过任务操作重新继续。
- 角色死亡、昏迷、掉线或长时间无法恢复时，自动流程会暂停，避免反复执行恢复指令。
