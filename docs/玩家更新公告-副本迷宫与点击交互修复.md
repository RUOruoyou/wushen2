# 玩家更新公告发布记录

> 状态：已于 2026-08-08 23:20:30 发布。公告 ID：`notice_1367919905a47291686e763b`。

## 标题

【江湖修复】副本迷宫地图与点击操作优化

## 摘要

修复桃花岛桃花阵在地图中缺少九宫房间、玩家无法通过界面完成迷宫操作的问题，并统一补齐多个后续副本的点击式机关和路线选项。

## 主要更新

- 桃花岛地图现在会完整显示 3×3 的九个桃花林房间，以及桃林出口、小路、试剑亭和庄院等后续区域。
- 桃花阵恢复八种九宫排列，进入阵法后会从一棵桃树所在房间开始，需要按一至九依次辨认；走错方向会回到起点重新破阵。
- 桃花阵提供北、东北、东、东南、南、西南、西、西北八个方向按钮，全程可以直接点击操作。
- 移花宫床榻机关、古墓水路、侠客岛答题、净念禅宗路线、慈航静斋路线与七苦门、阴阳谷路线、战神殿机关等交互均补充为可点击选项。
- 进入带有机关、答题或迷宫操作的房间时，动作栏会自动展开，避免遗漏关键按钮。

## 玩家提示

- 在桃花阵中请先查看当前房间的桃树数量，再通过动作栏选择方向；地图用于显示九宫位置，不能直接跳过阵法步骤。
- 其他副本遇到路线、数字、方向或答题选择时，请直接点击动作栏中的对应选项，无需手动输入命令。
- 本次只修复副本地图和操作流程，没有调整副本敌人数值、掉落概率、奖励或扫荡收益。
- 如仍遇到没有可点击按钮的副本节点，请提供副本名称、房间名称和当前界面截图。
