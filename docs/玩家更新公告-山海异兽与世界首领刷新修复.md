# 玩家更新公告草稿

> 状态：待用户确认，尚未发布。

## 标题

【江湖修复】山海异兽与世界首领刷新优化

## 摘要

优化山海异兽的每日出现节奏，并修复部分境界的世界首领无法正常刷新的问题。

## 主要更新

- 山海异兽每天的总数量保持不变，刷新批次调整为更均匀的时间分布。
- 减少山海异兽连续数小时不出现的情况，白天至夜间会有更稳定的讨伐机会。
- 修复武士、武师等境界的世界首领在副本进度提升后无法正常出现的问题。
- 单个境界的首领生成异常时，不再影响其他境界的世界首领刷新。

## 玩家提示

- 山海异兽仍为随机地点出现，每只异兽现世后只停留10分钟，请留意传闻和活动入口。
- 每日异兽总量、战斗难度、奖励门槛和奖励内容均未调整。
- 世界首领仍按原有时间和参与规则刷新，本次不调整首领属性、掉落或挑战次数。
